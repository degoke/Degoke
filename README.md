# Adegoke Adewoye

I build infrastructure for **healthcare, AI, cloud systems, developer tools, and distributed applications**.

My work focuses on creating reliable systems that can operate locally, at the edge, on private infrastructure, or in the cloud.

## Selected Projects

### [Health AI Stack](https://github.com/degoke/health-ai-stack)

Modular Go libraries for building FHIR-native health data infrastructure with safe AI access.

Supports offline-first applications, embedded FHIR stores, edge and cloud repositories, synchronization, analytics, SMART on FHIR, subscriptions, and permissioned AI tools.

`Go` · `FHIR` · `SQLite` · `PostgreSQL` · `Healthcare AI`

---

### [Geass](https://github.com/degoke/geass)

A managed-cloud experience for your own VPS or bare-metal infrastructure.

Geass uses K3s to turn individual servers or clusters into a unified environment for deploying applications, databases, storage, and networking without depending on a major cloud platform.

`Go` · `K3s` · `Kubernetes` · `Cloud Infrastructure`

---

### [Outpost](https://github.com/degoke/outpost)

A remote development environment controlled from your local terminal.

Run Docker Compose applications, Kubernetes clusters, development commands, and lightweight Linux machines on a remote server without installing the complete infrastructure stack on your laptop.

`Go` · `Docker` · `Kubernetes` · `SSH` · `Incus` · `AWS`

---

### [Tronvent](https://github.com/degoke/tronvent)

A self-hosted transaction and event monitor for the TRON blockchain.

Tronvent watches TRX and TRC-20 activity through TronGrid, maintains a durable scanning state, and delivers matched transactions to applications using signed webhooks.

`Go` · `PostgreSQL` · `TRON` · `Webhooks` · `Docker` · `Helm`
